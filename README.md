My Learning Companion 🌐📚
  My Learning Companion is a productivity-enhancing Chrome Extension integrated with a real-time dashboard. It allows users to select, save, and organize learning content directly from any webpage, making managing and revisiting useful information across sessions easier.

🚀 Features
  ✨ Highlight & Save: Select any text on a webpage and save it instantly with a custom title and timestamp.
  📊 Interactive Dashboard: View saved content in an organized, searchable format with date, time, and titles.
  ⚡ Real-Time Sync: Saved content is instantly available on the dashboard without refreshing.
  🗂️ Sorting & Searching: Easily sort and search saved content by title or timestamp.
  🔒 Future-Ready: Planned enhancements include user authentication, persistent cloud storage, and AI-based content tagging.

🧱 Project Architecture
Frontend:
  Chrome Extension (HTML, CSS, JavaScript)
  Dashboard Website (HTML, CSS, JavaScript)

Backend:
  Node.js + Express.js
  REST APIs for saving and retrieving content

  Backend Setup

bash
  cd backend
  npm install
  node server.js

Load the Chrome Extension
  Open Chrome and go to chrome://extensions/
  Enable Developer Mode
  Click on Load Unpacked and select the extension folder

Open the Dashboard
  Run dashboard.html in any browser or set up a local web server
